Guided tour & contextual help — system spec

One reusable pattern, applied to every provider nav page. A first-visit tour teaches the page; a persistent ? in the header reopens that page's help and replays its tour. Each page supplies only its own step list and help copy.

Spotlight — the target element is measured with getBoundingClientRect and cut out of a 60%-black scrim, ringed in #03d3bf. It animates between steps.
Step counter & progress dots — position in the page's step list. The list length is per page (5–8 steps).

First-visit trigger

When the tour fires

On mount of a nav page's main route, if that page's seen-flag is absent. It never fires on a sub-route, drawer, or modal — only the page a nav item points at.

Skipping or finishing sets the flag. The ? → Take tour again replays it without touching the flag.

// one flag per page — survives reloads, per device
const key = `practmd.provider.tour.${pageId}`; // today | calendar | …
if (!localStorage.getItem(key)) startTour();
// on skip / finish
localStorage.setItem(key, 'seen');

Per-page step schema

A page contributes an ordered array. Each step names a target by id (or "help-btn" for the last), a title, and one sentence of body. Nothing else is page-specific.

steps: [
{ id: 'kpi-unsigned',
title: 'Unsigned notes come first',
body: '…one sentence…' },
// …3–6 more…
{ id: 'help-btn', isHelpBtn: true,
title: "That's the tour", … },
]

The ? help panel

Placement & states

A 32px icon button in the global header, between the clinic switcher and the notification bell. Present on every page.

Default — quiet grey. Tour's final step — spotlit, tinted #ecfefb. Panel open — stays tinted. Clicking toggles the panel; it's inert while the welcome card is up.

Panel contents (module-scoped)

A right slide-over titled Help · {module}. One intro line, then In this section — 4–5 short doc blocks specific to that page — then a fixed Help resources list, then a sticky Take the {module} tour again button.

Coverage

Every nav destination gets its own tour + help copy: Today, Calendar, List, Encounter Notes, Waiting Room, Messages, Patients, Tasks, Reports, Recents, My Availability, Settings, Profile. Sub-pages (a patient chart, a SOAP note, an appointment drawer) inherit the parent's ? but do not auto-trigger a tour.
